# Regras do projeto

## Mensagens de commit

Todos os commits devem seguir o padrão Conventional Commits: `tipo: descrição` ou `tipo(escopo): descrição`.
O prefixo semântico é obrigatório. Use `feat` para novas funcionalidades, `fix` para correções, `docs` para documentação, `refactor` para refatorações, `test` para testes e `chore` para manutenção.
Mantenha a descrição simples e descritiva, preferencialmente em português, explicando a alteração.

Exemplos: `feat: adiciona a fase Travessia da Lagoa`, `fix: melhora os controles de toque no celular` e `docs: exige commits semânticos nas regras do projeto`.
